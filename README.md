# Library-management-system-project-
Library Management System 

The Library Management System is a console-based project developed using the Data Structures and Algorithms (DSA). It helps manage library operations such as adding new books, displaying book records, searching for books, issuing books, and returning books.

This project demonstrates the practical implementation of data structures, structures, functions, loops, and conditional statements . It provides a simple and efficient way to organize book information and understand how library management systems work.

Features

- Add new books
- Display all available books
- Search books by ID or title
- Issue books to students
- Return issued books
- Update and manage book records
- Simple menu-driven interface

Technologies Used

- Programming Language: C
- Concepts: Data Structures and Algorithms (DSA)
- Tools: GCC Compiler / Code::Blocks / VS Code

Objective

The main objective of this project is to apply C programming and DSA concepts to solve a real-world problem while improving programming, logical thinking, and problem-solving skills.

Learning Outcomes

This project helps beginners understand data management, searching, record handling, and the practical use of data structures in C.
